## Selected public projects

### [CML Local Alpha](https://github.com/cstolting-collab/CML-Local-Alpha)

Local-only tools for static CML document validation, accepted-state recovery, and verification receipts. This is alpha software with a defined static-checking scope; it does not certify runtime correctness or safety.

### [CML Trust](https://github.com/cstolting-collab/CML-Trust)

An alpha evidence notebook for recording external continuity observations and preserving their supporting history. Its documentation explains the distinction between an observation and an accepted state.

## How I work

I start with the existing state and a clearly scoped problem, keep proposed changes reviewable, and record the checks and unresolved questions before handoff.

**Accepted state → observation → candidate change → validation → explicit human-authorized commit**

Work is human-led and AI-assisted. Original projects and contributions to upstream projects are identified separately, with authorship and licenses preserved. Historical results remain dated so they can be assessed in context.
