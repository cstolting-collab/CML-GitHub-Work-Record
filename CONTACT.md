# Work with S.J. · Estra Logics

Open to collaboration and contract work in software investigation, validation tooling, engineering production, and technical documentation.

## Start a public project inquiry

[Open a project inquiry](https://github.com/cstolting-collab/CML-GitHub-Work-Record/issues/new?title=Professional%20inquiry)

A short introduction is enough:

- What problem are you trying to solve?
- What outcome or deliverable would help?
- Is there a public repository, issue, or example to inspect?
- What timing or other constraints should I know?

**GitHub issues are public and require a GitHub account.** Include only details suitable for public discussion. For confidential work, keep the introduction general and ask to arrange a private conversation before sharing project material.

For a bug in a particular tool, use that project's issue tracker so the report stays with its source.
